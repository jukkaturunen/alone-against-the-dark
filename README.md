# Alone Against the Dark

A personal web adaptation of the solo Call of Cthulhu adventure.

Status: high-level plan approved; UI design comes next. Game implementation has not started.

## Direction

A faithful, atmospheric digital gamebook. The player makes decisions and solves the mystery; the app handles navigation, dice, rules, and bookkeeping. No live AI narrator or generated story branches are planned.

The eventual hosting target is Vercel. The repository is private; deployment access will be decided separately.

## Local source material

The owner supplies three PDFs in `src/`: the adventure, its handouts and ready-made investigators, and the Keeper Rulebook. These originals are excluded from Git and must not be uploaded as site assets. A fresh clone does not include them.

No framework or dependencies have been selected yet. There is no runnable app at this stage.
